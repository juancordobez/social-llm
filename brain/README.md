# 🧠 Brain Module

Módulo de desarrollo del cerebro de Social Mimic - Sistema de IA/ML para análisis de personalidad, memoria RAG y toma de decisiones.

## 📁 Estructura

```
brain/
├── core/                 # Motor cognitivo principal
├── adapters/            # Adaptadores para modelos de IA
├── notebooks/           # Experimentación en Jupyter
├── experiments/         # Experimentos ML
├── deployment/          # Configuraciones de modelo
└── requirements.txt     # Dependencias Python
```

## 🚀 Setup Rápido

```bash
cd brain
pip install -r requirements.txt
```

## 📚 Componentes Principales

- **PersonalityEngine**: Análisis de personalidad y generación de prompts
- **MemorySystem**: Sistema RAG para contexto y memoria
- **DecisionMaker**: Motor de decisiones para acciones sociales
