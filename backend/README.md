# 🔧 Backend Module

Módulo backend de Social Mimic - APIs REST, funciones Lambda y adaptadores de servicios.

## 📁 Estructura

```
backend/
├── api/                 # APIs REST principales
├── lambdas/            # Funciones serverless
├── shared/             # Código compartido
├── infrastructure/     # Infrastructure as Code
└── package.json        # Dependencias Node.js
```

## 🚀 Setup Rápido

```bash
cd backend
npm install
npm run dev
```

## 📚 Componentes Principales

- **API REST**: Endpoints para interactuar con el cerebro
- **Lambda Functions**: Funciones serverless para procesamiento
- **Adapters**: Abstracción de servicios externos
